# Projects

The Projects area stores developer-owned project records in the Neon database
connected to the **Ori Developer Platform** Vercel project.

## Apply the database migration

1. Open the Neon project connected to the Ori Developer Platform.
2. Open its SQL Editor.
3. Run the contents of `db/migrations/001_create_projects.sql` from this repository.
4. Return to the developer platform and refresh **Projects**.

The migration only creates the `ori_dev_projects` table and its owner/date index.
It does not alter existing Ori Platform or Ori Intelligence tables.

## Data isolation

- Every record is associated with the authenticated Clerk user ID.
- The API obtains the owner ID from Clerk on the server; it never accepts an owner ID from the browser.
- List and create queries are scoped to that authenticated owner.
- API responses never include database connection details.

## API

- `GET /api/projects` — list up to 100 projects owned by the signed-in user.
- `POST /api/projects` — create a project with a name and optional description.

Names must be 2–60 characters. Descriptions are limited to 240 characters.
Project slugs are generated by the server and are unique per owner.

Database migrations are intentionally manual for now. Deployments do not execute
schema changes automatically.
